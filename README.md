# EFB v2 — 0.2.15 图形安装器 / LAN Bridge preview

把现有 PMDG EFB v2 接入局域网。页面在 iPad / 电脑浏览器本地排版，传输 DOM 状态差异、图片资源、Canvas 2D 绘图指令和操作事件，**不发送截图或视频流**。计算、飞机操作、SimVar/LVar、CommBus 仍由模拟器内原版 EFB 执行。

这是需要在真实 MSFS 2024 中验证的首版，不是已完成实飞认证的发行版。浏览器与选定的 CA / FO 平板共用页面及状态；不是第三台独立 EFB。模拟器必须加载飞机并让相应 EFB 运行。

## 安装

0.2.9 移除 LAN 外层顶栏，将 CA/FO 和 Re-sync 放入 EFB 原生顶栏时间右侧的空位；等待连接时仍可切换平板或重新同步。补上航图机场输入框旁的加载旋转动画。上述界面改动仅在 LAN 浏览器生效。

0.2.8 在 LAN 地图处于 Navigraph 模式时显示 NAVI MAP INOP；切回 PMDG 自动消失。提示不拦截点击/拖拽，只存在于浏览器端，模拟器 EFB 不受影响。当前开发工作目录已迁移至 B:\Developing\pmdg-tablet\efb-lan；构建脚本仍会自动更新发行软件包的 layout.json。

同时改用 CSS 绘制下拉箭头，加入地图单指拖拽到模拟器鼠标事件的转换，并兼容 Leaflet 的主键检测。Navigraph 图片读取增加二进制格式识别；配对后访问 `/diagnostics` 可查看模拟器端图片读取错误（HTTP 状态、网络/CORS、图片解析等），不包含登录凭据。真实 Navigraph 瓦片问题仍待实机验证，地图跟随/锁定状态继续遵循原生 EFB。

1. 退出 MSFS 2024，解压整个 `EfbV2-LAN-win-x64.zip`。
2. 双击 **EfbV2Setup.exe**。这是 .NET 编写的图形安装器，自带运行时，无需预装 .NET，也不会请求管理员权限。旧的 Install.cmd / Install.ps1 现在只打开该窗口，不再执行旧安装逻辑。
3. 选择 **仅安装 EFB** 或 **安装 EFB + LAN 服务**。前者保留 GSX、BATC 和落地分析，不安装 LAN 程序和桥接脚本；后者增加局域网访问。已有 LAN 安装也可切回仅 EFB，会移除服务和本工具自己的自动启动项。
4. 安装器检测 Steam / Microsoft Store 的 MSFS 2024 配置，从 `UserCfg.opt` 读取 Community / Community2024 路径。多目录出现在下拉列表中；也可以点“浏览”手动选择。仅 EFB 模式不要求 UserCfg.opt。LAN 自动启动需要选择含 UserCfg.opt 的配置目录；也可取消自动启动后手动运行服务。
5. 点击 **安装 / 更新**。安装器直接更新 Community 中的 `pmdg-tablet-v2`，不创建备份或执行回滚，不修改 PMDG 厂商飞机软件包。错误原因显示在窗口内并保存日志；若文件更新中途失败，排除原因后重新安装即可。临时目录只存放新安装包的待安装文件，完成或失败后清理。
6. LAN 模式安装完成后会显示地址和配对码。用同一局域网设备打开 `http://模拟器电脑IPv4:8385/`。启动 MSFS 2024 并打开飞机 EFB，在网页选择 CA 或 FO。

开始菜单的 **EFB v2 LAN → EFB v2 安装与管理** 可启动/停止服务、显示连接信息、编辑配置、应用端口和卸载。管理器会复制到用户目录，删除解压目录后仍能使用；安装/更新需再次打开完整解压包中的安装器。详细日志位于 `%LOCALAPPDATA%\EfbV2Bridge\logs\setup-*.log`。

0.2.3 使用 **4 位纯数字配对码**，输入框支持移动设备数字键盘。更新时旧长码自动换成新 4 位码，查看安装完成后的连接信息，并在其他设备重新配对一次；以后的更新保留已有 4 位码和端口。短码仅用于配对，登录 cookie 使用由模拟器密钥派生的长令牌；配对接口每分钟最多接受 5 次请求，已配对连接不受此限制。

落地分析的本次数据及历史详情均以 G 值为首项，采用原接地率的半宽、大号蓝色样式；接地率移到第二项，使用普通数值样式。计算逻辑和历史数据格式不变，737 与三个 777 型号同步更新。

0.2.2 修复 LAN 服务已启动但网页始终等待飞机的问题：旧发行副本可能缺少平板 HTML 中的桥接脚本导入，旧安装器仅写配置而不补入口。现在 LAN 安装会给所有 CA / FO 页面补齐配置和适配器导入，并去重；复用旧副本打包也会重新生成入口。受影响安装请退出模拟器，用新包选择 **安装 EFB + LAN 服务 → 安装 / 更新**，然后重新启动模拟器。不必先卸载。

程序本身按普通用户权限运行。如果 Community 是受保护目录，需由该用户获得写入权限。Windows 防火墙若阻止入站连接，需要允许该程序在“专用网络”通信；组织管理的防火墙可能要求管理员批准。安装器不会修改防火墙，也不会设置路由器端口转发。

## 端口与配置

0.2.4 增加原生图片转交：模拟器读取航图的 Blob 数据和带现有登录 Cookie 的 Navigraph 瓦片，再分块传给桥接器。iPad 通过已配对的同源接口加载图片，不需要独立 Navigraph 登录；桥接器不接收 Navigraph 令牌或 Cookie，也不直接登录 Navigraph。资源仅缓存在内存中，按 CA/FO 及宿主会话隔离，宿主断开后清除；原生脚本会在重连后重新传送仍在使用的图片。单张图片上限 12 MiB，超过两分钟未引用的资源被移除。原始样式表链接随页面同步，以恢复字体图标及图片背景。

模拟器内仍须正常登录 Navigraph，且原生航图、地图本身可显示。此版已用模拟私有瓦片和实际桥接服务验证，Coherent 读取图片及 iPad Safari 效果仍需实机验证。其他类型的外部嵌入页面并未因此获得完整支持。

`%LOCALAPPDATA%\EfbV2Bridge\bridge.json`：

| 字段 | 默认值 / 用途 |
| --- | --- |
| Port | `8385`，HTTP 与 WebSocket 共用此端口 |
| BindAddress | `0.0.0.0`，监听本机 IPv4 网卡 |
| PackagePath | 安装后的 EFB v2 路径 |
| PairingKey | 随机生成的 4 位数字字符串，保留前导零，例如 `"0042"` |
| HostKey | 仅供本机模拟器连接的密钥 |
| GsxPort | `8744`，GSX 自有 Remote 服务端口 |
| BatcPort | `41716`，BATC 服务端口 |

退出模拟器，在图形管理器中设置端口并点击 **应用端口**。程序检查端口、同步模拟器端配置、重建 `layout.json`；原本正在运行的服务会重启。也可用“打开配置”修改 JSON，再重启桥接器和模拟器。下次进入飞机后生效，其他设备改用新 URL。端口冲突会明确报错，不会自动随机换端口。

## 启动与通信

- 自动启动使用 MSFS `exe.xml` 的 `Launch.Addon`，只增改名为 `EFB v2 LAN Bridge` 的条目，保留其他软件的条目。参考 [BetterBravoLights 的安装实现](https://github.com/RoystonS/BetterBravoLights/blob/main/BravoLights/Installation/Installer.cs)：其外部程序由 `exe.xml` 启动，WASM 是另一部分，不负责启动进程。本桥接无需额外 WASM。
- 模拟器启动的桥接器在模拟器退出后自动退出。手动启动的实例需要手动 Stop。
- 原生页面：浏览器事件 → 本机桥接 → 模拟器内 DOM 事件 → PMDG 原有逻辑 → CommBus / SimVar → 页面状态返回。iPad 可以点击 Calculate，无需再点击模拟器内同一个按钮。
- GSX / BATC：iframe 在设备本地运行原有前端，WebSocket 经同源代理到本机 GSX / BATC 服务。桥接器不实现自动应答、登机或菜单保活逻辑，也不会重放服务指令。
- GSX 沿用现有 EFB 页面的菜单接管逻辑；GSX Remote 服务及 BATC 必须已运行。GSX 实际监听端口若不是 8744，请修改 `GsxPort`。
- Landing Analysis：使用模拟器内现有计算和历史存储，不在浏览器生成第二份落地记录。
- 断线时网页停止发送操作，重连请求完整状态。事件不排队、不在重连后重放；超过 3 秒的迟到事件或旧会话事件会丢弃。没有浏览器订阅时不扫描 DOM。
- 配对 cookie 是 HttpOnly / SameSite Strict；远程 WebSocket 检查 Origin。模拟器连接仅接受 loopback 地址和 HostKey。接口没有执行任意代码或任意 SimVar 写入的能力。

## 首版边界与验证

- 普通 HTML / SVG、输入框、按钮、选项、滚动、现有 GSX / BATC 页面是此版重点。
- 常规 Canvas 2D 指令在浏览器重新绘制；Blob 图片可通过资源转交显示。WebGL、像素操作、复杂 Pattern / Gradient、Canvas-to-Canvas 及未知第三方 iframe 暂无完整适配。遇到不支持的 Canvas 操作会显示虚线边框及提示，不能把它当作已正确显示。PMDG 当前 Navigraph 实现使用图片航图和栅格瓦片，已针对这两条路径适配；PDF、其他地图或第三方页面仍需独立适配。
- 性能计算结果来自原 EFB / 飞机，桥接器不替换算法。真实 CommBus 通路、Coherent 对脚本 API 的兼容性以及 iPad Safari 触摸交互仍需实际 MSFS 验证。
- 网页同步的是平板 UI，不绕过平板供电、初始化或飞机状态限制。不要把没有飞行环境的浏览器测试当作实飞通过。
- 本地测试脚本覆盖鉴权、状态恢复、事件传递、输入、侧别隔离、服务代理及安装/卸载。测试结果见开发目录 `tests`。

如果本机地址可打开但其他设备打不开，先检查两台设备是否处于同一 LAN、是否开启访客 Wi-Fi 隔离，以及 Windows 专用网络入站权限。此版是受信任 LAN 内的 HTTP 服务，不用于公网暴露。

## 卸载

退出模拟器，打开图形管理器，点击 **卸载**。它移除 `pmdg-tablet-v2`、自己的自动启动项和服务文件，不恢复旧版本。管理器、配置和日志保留在用户目录。以前版本创建的备份不会被新安装器访问或删除，可按需自行处理。

## 开发构建

需要 .NET 9 SDK；运行 `Build.ps1 -PackagePath '现有v2副本路径'`。源包只读，桥接代码只注入 `dist/EfbV2-LAN/package/pmdg-tablet-v2`，绝不直接修改 Community 中的源码。输出 ZIP 含本人的 PMDG 页面及本地修改，仅供自己使用，不应公开分发 PMDG 商业资源。

`Setup/` 是 C# / WinForms 图形安装器与安装逻辑；`host/lan-bridge-host.js` 为模拟器适配器，`web/` 为浏览器渲染器，`Bridge/` 为本机服务。`installer/` 只保留旧脚本作为历史参考，发行包不再使用其安装逻辑。不需要修改 PMDG 的大型业务 JS。仅更新安装器时可用 `Build.ps1 -ReusePackage` 复用现有打包副本。
